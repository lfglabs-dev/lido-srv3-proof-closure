## Required internal obligations still open

The initial `activeWords < 2^251` bound is retained and must be derived from real initialization and all preceding compiled transitions. It is not an external trust boundary. At 2^251 the engine's uint256 extent-times-32 calculation wraps; a synthetic returned state can pass the actual BLS flag/size guard while mload reads zero. Therefore successful guard inversion alone does not derive the missing invariant. Default initialization and scratch-write examples only check those particular transitions, not the complete entry path.

The independent raw-public-key byte digest, complete raw-byte/typed-tree equivalence and proof-fold success correspondence remain necessary. So do the slot/proposer/root/GIndex prefix, actual root lookup, compiler allocations/free-pointer panics and spills, surrounding opcode gas, exact error bytes and compiled World/rollback. The inherited `Theta` created-account reset prevents treating caller-environment preservation as a full World frame. SSZ checks only the call flag whereas BLS also checks output size; this BLS proof does not transfer that size guard into SSZ.

SHA implementation correctness/cryptography and authentic consensus/deployed configuration remain external trust with no new deployment verification. All eight guarantees remain OPEN. This is a compositional increment, not full SSZ delivery. A frozen exact-source independent review is required before integration.
