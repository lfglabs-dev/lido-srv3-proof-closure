# Pinned Verity runtime boundary

Library.lean executes the byte decoder and proportional consumer through the
pinned Verity Contract.run. Success returns bytes; revert reasons use exact hex
because this Verity API stores reasons as String. The universal run_exact and
state_preserved theorems bind the outcome and entire ContractState, including
memory, calls, events and storage. canonical_outcome retains the explicit byte
extent premise from LibraryABI.

This is an EDSL runtime adapter to the source interpreter. It does not execute
compiler-generated bytecode, implement compiler dispatch or establish physical
memory allocation/copy correspondence. Those remain separate obligations.

prepare.py creates an exact source overlay in the private base worktree,
including the root's complete pinned dependency manifest. Build remotely from
../temp/alloc2-runtime/audit/trio/alloc2/runtime with remote-lean-build lake build.
Vectors.lean emits eleven executions of Contract.run, paired by exact input and
output with the existing ABI vectors. The Solidity runner accepts the successful
runtime receipt as its fourth argument after the two earlier receipts and
requires the full current source manifest to match the verified remote overlay.
