# Actual WstETH unwrap joined to the withdrawal request

This increment replaces the arbitrary unwrap reply in the accepted wrapped-request caller with the pinned WstETH unwrap implementation. The public theorem joins the token's actual conversion, qualified burn and STETH transfer to the same decoded amount, returned world, quote, physical enqueue and journal of the previous request effect. The queue burns its own WSTETH holdings after transferFrom, not the requesting user's balance directly. All previous source files and public claims are unchanged.

## Executed body and public consumer

`calleeFor` selects the actual unwrap implementation for the WSTETH target and unwrap selector, checks nonpayable value/minimum calldata length, and decodes the uint256 argument. `canonical_call` proves that the exact calldata generated by the existing WithdrawalQueue caller executes that body with token context `(self = WSTETH, sender = queue)` and the same amount. Other requests, including the queue's first WSTETH transferFrom, use the explicit external implementation.

The new token body follows WstETH.sol 69–75, OpenZeppelin 3.4.0 ERC20._burn and the actual solc0.6.12 assembly:

1. Reject zero wrapped amount.
2. Read WSTETH's stored stETH address at physical slot 7, truncate its address value to 160 bits, and make the actual conversion STATICCALL `getPooledEthByShares(amount)`. Decode the first returned uint256 with the minimum-32-byte check.
3. Check the burn account is nonzero. Read the WSTETH-qualified `_balances[queue]` mapping slot, check/subtract the amount, then write that balance. Read `_totalSupply` slot 2 **after** the balance write, check/subtract it, then emit the burn Transfer. The concrete inherited hook is empty. No storage nonalias premise or simultaneous pre-read is supplied.
4. Re-read stETH slot 7 after the burn, call `transfer(queue, convertedAmount)` on that address, and retain its actual returned world. The compiler checks minimum return length and ignores the bool result, including noncanonical word 2. The model's word decoder merely records an ignored observation of the first word; it imposes no extra bool-canonicality condition. This is deliberately different from the caller's solc0.8.9 transferFrom bool decoder.
5. ABI-encode the captured converted amount as the unwrap CALL return, retaining the nested conversion/transfer journal and its static flags. Rejection uses the existing Error(string)/empty/bubbled reply encoding; a rejected callee exposes no committed world.

`actual_wrapped_token_request_enqueue` assumes only the whole joined runner returned successfully. `JoinedEffect` retains the **entire previous** `AddressWrappedRequestCalls.RequestEffect` and adds the token effect bound to the very same transferred and unwrapped worlds, converted amount, quote, enqueue, and attempts. The amount checked/enqueued by the queue equals the amount computed by the token's actual conversion and returned after its STETH transfer. No internal-stage success, received payload, frame or balance-fit premise is introduced. `actual_wrapped_token_request_failure_restores` restores the complete entry world, including the burn and both mutable callee effects, for every failure of this joined runner.

`BurnEffect` exposes the source-ordered intermediate balance write and subsequent supply read/write. It does not assert final balance/supply values after an arbitrary STETH callback. The actual Solidity fixture demonstrates why: the STETH transfer double calls the real WstETH.wrap, so totalSupply becomes 5 after the burn and the queue request still succeeds. The model's corresponding diagnostic preserves such a returned-world change.

## Limits preserved

The model now executes the WstETH unwrap body, rather than the older standalone root-lens unwrap helper. Token storage accesses use `readContractSlot/writeContractSlot` at WSTETH's address; the queue keeps its accepted designated storage lens. The native diagnostic includes incorrect unqualified balance/supply decoys and confirms they remain untouched.

First transferFrom, conversion and STETH transfer/quote implementations remain explicit external interfaces. Deployment, initial token balances/allowances/layout provenance, the queue/token configured-address relation, initial pause/permit/batch/outer ABI setup, general compiler/EVM/gas/memory/LOG equivalence and cryptographic implementation correspondence are not established. The token address is read at its actual execution points; no equality between its pre-burn and post-burn value or the queue's configured STETH address is assumed. The external model admits arbitrary callback worlds. This lot proves no final token conservation through those callbacks. The canonical-call theorem binds the real generated caller calldata; it is not a complete malformed-dispatch equivalence theorem. The queue's custom-error categories and semantic events retain the previous scope rather than acquiring a new raw-byte theorem.

The earlier public caller remains available with arbitrary unwrap externals and can accept a zero wrapped input if its callee does. This additional actual-token consumer rejects zero through executed token code. No earlier theorem domain or guarantee status is reduced or upgraded.
