# SSZ primitive calldata loop and initial CALL budget

At core `17005714f151e5502c559932319a3f2f74ac2436`, this lot composes the accepted raw calldata step through the entire helper, including the empty-proof guard and final index/root checks. `verify_success_iff` proves that successful execution of this primitive-based interpreter is equivalent to a nonempty independent Merkle `Branch` over the same opaque FFI-backed word hash. It does not assume a successful fold, expected digest, root equality, or individual successful CALL outcomes.

`loop` follows each actual `sourceStep` result's continuation flag and offset. Its natural round counter is interpreter fuel; the theorem supplies the decoded proof length and derives termination from the actual pointer comparison. Each SHA call separately uses the accepted CALL/Theta fuel convention. This is not execution of compiled bytecode or the EVM X opcode dispatcher.

`SszProofLoopResources` derives access charges, admission, returned word gas, unchanged caller environment and memory-size bounds from the actual engine CALL and SHA precompile. Cold admission needs 2685 units: 2600 access plus 84 SHA plus the EIP-150 retained unit. The conservative initial bound `2684 * proof.length + 1` derives each successive CALL admission without a per-iteration resource hypothesis. It conservatively allows a cold access every round. An independent branch and the decoded uint248 index imply at most 247 siblings and a CALL-only bound at most 662949. **These are not total Solidity transaction gas bounds:** surrounding memory, arithmetic and control opcodes are not charged by this interpreter.

The initial calldata must equal `prefix ++ fixedBE32(proof) ++ suffix` and have size below 2^256. The decoded ABI count is supplied as the proof's natural length; extracting this representation from a real ABI decoder remains open. Initial depth is below 1024 and active memory words below 2^251. The opaque FFI must return 32 bytes on every pair of fixed-width words; the Solidity helper itself has no return-size guard. The theorem uses the same opaque pair hash on both sides, without proving standard SHA, typed leaf/entry adapters, cryptography, consensus membership or root provenance. Error tags preserve the modeled order, but do not establish revert selector encoding or transaction rollback. Caller environment preservation is not a full World/account frame theorem.

The two source modules contain 27 public theorems. The test module has 29 kernel examples and ten principal axiom queries, restricted to propext, Classical.choice and Quot.sound. Examples exercise actual cold/warm gas thresholds, the retained unit, initial budget arithmetic, loop fuel and depth failures, decoded index and empty-guard priority, and standalone final checks. Final-check fixtures are not claimed to be successful hash paths.

`fresh-validation.json` binds before/after identities for three fresh direct Lean checks and a targeted Lake replay. Imported caches are reused, so this is not a full dependency rebuild. The targeted graph has 1130 jobs; the direct test check reruns all new kernel examples independently of that replay. `dependency-inputs.json` records actual package-source imports and selected core sources, with existing sources compared to Git HEAD. It does not certify compiled dependency binaries or a complete Lean toolchain closure. Earlier calldata-step and SHA-call receipts are retained by identity, without claiming their tests were rerun here.
