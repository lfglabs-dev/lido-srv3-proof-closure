# Independent raw key bytes in the actual SSZ witness consumer

The pinned BLS length-48 primitive performs `mstore(0x20,0)` and `calldatacopy(0,offset,48)` before SHA. This increment proves that exact scratch block for every calldata byte array and every uint256 offset, including short and wholly absent data, without adding a calldata-extent, canonical-offset or small-array premise. `keyBytes` is the independent 48-byte zero-extended view, and `blockBytes` appends sixteen zeros. The actual cleared memory shape ensures the existing engine copy has space to zero-fill; arbitrary old memory above byte 64 is preserved.

`copy_padded`, `memory_exact` and `read_exact` unfold the existing EvmYul byte operations, including bounded USize zero padding. `block_eq_raw` agrees with the previously accepted unpadded view when the extent fits; that condition is not required by the new consumer. `pubkey_success_digest` derives the actual key-call digest, output bytes and length from its executed guard and actual SHA call. Depth, precompile gas, input block size and opaque FFI output size are discharged from that execution and scratch proof. The existing initial activeWords below 2^251 bound remains required.

`witnessAt` uses these same independent key bytes and the decoded fields. `witness_key_length` derives exactly 48 bytes; `pubkey_digest_typed` and `computed_leaf_typed` relate the digest to the existing typed validator tree. `run_success_computed_leaf` consumes success of the unchanged SszWitnessAbi.run: the actual proof verifier receives that typed tree digest, original credentials/root/GIndex/proof slice and the actual returned leaf state. The adapter is used in the consumer theorem, not held as an unused payload. Signed relative-pointer behavior and original-calldata binding are inherited unchanged.

## Checks and limits

Eleven public theorems and one private guard-inversion helper compile. Three named kernel-checked regression/mutant theorems plus six kernel examples exercise the actual scratch operations with dirty memory, 47-byte and 48-byte keys, offsets at and beyond the data end, the maximum uint256 offset, preservation above scratch, and the old in-bounds bridge. The dirty-padding mutant differs from the real scratch result at the missing 48th byte. These are primitive-memory tests, not evidence that malformed keys reach the Solidity wrapper or that opaque SHA executes in the kernel. Fifteen axiom-query occurrences cover fourteen distinct declarations with only propext, Classical.choice and Quot.sound. Final target build15 passes 1,136 jobs. Earlier build failures are retained as diagnostics and corrected, not treated as verification.

No fresh Forge execution is claimed. Pinned BLS/SSZ/CLValidatorVerifier and accepted wrapper compiler evidence are reused by exact identity. The generalized zero-padding cases extend the primitive's mathematical input domain; the actual compiled decoder's accepted extent and full wrapper execution still require their own correspondence. The independent tree uses the same opaque SHA specification, without claiming cryptographic correctness.

## Required internal obligations still open

The initial activeWords bound must be derived from actual initialization and all preceding compiled transitions. This increment neither narrows the calldata domain nor declares this memory invariant external. Complete proof-fold success correspondence remains open: SSZ checks the call flag only and cannot inherit BLS's returned-size guard. Full slot/proposer/root/GIndex prefix and actual root lookup, compiler allocations/free-pointer panics/spills, surrounding opcode gas, exact error bytes and compiled World/rollback remain necessary. The inherited Theta created-account reset prevents a full World frame. Authentic consensus/deployed configuration and SHA implementation/cryptographic correctness remain external trust without new deployment verification.

All eight guarantees remain OPEN; ALLOC-1, ALLOC-2 and RESERVE-1 remain accepted and outside the improvement queue. This increment depends on the exact SSZ committed-call proof in PR293. Independent full-source review and integration are still required before site credit.
