Off-chain actors · they pick when & what: contracts bound how much

Depositor Bot
collects guardian signatures, picks module & timing, builds top-up Merkle proofs. Compromise = liveness problem, not funds.
Oracle daemons ×9
compute reports on a shared reference slot: deterministic and replayable by anyone.
Node operators
hold signing keys only; withdrawal credentials of every Lido validator point to the WithdrawalVault, so principal is out of reach.

Governance & committees

DepositSecurityModule + guardians
contracts/0.8.9/DepositSecurityModule.sol
0xF573…e9Be
an EL contract with a committee-held key: it stores its own guardian set and quorum (:97-98, getGuardianQuorum :227-231). Guardians attest "deposit root unchanged, keys safe", then call StakingRouter.deposit(). Its only reach into consolidation is the isDepositsPaused() flag (:88) that ConsolidationGateway reads (:276-277): it cannot remove consolidation batches.
EasyTrack · EVMScriptExecutor
0xF021…3Fea
the executor is the sole grantee of ConsolidationMigrator.ALLOW_PAIR_ROLE (UpgradeTemporaryAdmin.sol:68,91-92; UpgradeTemplate.sol:339-340). That role only adds CMv1→CMv2 operator pairs. Removing a pair (DISALLOW_PAIR_ROLE) and removing a committed batch (Bus REMOVE_ROLE) go to the consolidation committee, not to EasyTrack.
HashConsensus
contracts/0.8.9/oracle/HashConsensus.sol
0xD624…B288
holds the oracle committee and the quorum: a report is processable only once support reaches the stored _quorum on an identical hash (:225, :455-461, :945). The oracle contracts themselves hold no quorum. This is the protocol's central trust assumption; the quorum is a governance-set number, not a constant.
Lido DAO (Aragon)
Voting 0x2e59…618e · Agent 0x3e40…9C8c
votes modules, roles, parameters; treasury receives its fee share.

Consolidation pipeline · all new in SRv3

ConsolidationMigrator
contracts/0.8.25/consolidation/ConsolidationMigrator.sol
holds its own allow-list of (source, target) operator pairs and the submitter designated for each (allowPair :181-185, isPairAllowed :239). Only the EasyTrack EVMScriptExecutor can add a pair; the committee can remove one (:200). Resolves key indices → pubkeys and sends the batch to the Bus (:306-324).
ConsolidationBus
contracts/0.8.25/consolidation/ConsolidationBus.sol
commit-delay-execute: hash binding, non-replay, and removeBatches (:250), gated on REMOVE_ROLE (:168). That role is the consolidation committee's, not the DSM guardians': the delay is the committee's veto window. An executor bot pays the EIP-7251 fee.
ConsolidationGateway
contracts/0.8.25/consolidation/ConsolidationGateway.sol · CLProofVerifier.sol
pausable; inherits CLProofVerifier (:12, :34), not the TopUpGateway's CLValidatorVerifier. Verifies target WC proofs and limits, reads the DSM isDepositsPaused() flag (:276-277), then WithdrawalVault.addConsolidationRequests{value: fee}.
EIP-4788 / 7002 / 7251
0x000F…ac02 · 0x0000…7002 · 0x0000…7251
execution-layer system predeploys, not consensus-layer components: Lido reaches all three with an ordinary staticcall / call from an EL contract. 4788 is the beacon-root anchor every proof is checked against; 7002 and 7251 accept exit and consolidation requests from the withdrawal address.
