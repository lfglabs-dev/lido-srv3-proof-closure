\section{Reproducibility and handoff}
\label{sec:reproducibility}

\subsection*{Reviewer command in a real delivery}

A reviewer does not need to trust the PDF alone. The handoff includes the proof
sources and commands that rebuild the selected theorem set and check that the
PDF's assumptions match the machine-readable trust-boundary report.

\smallskip
\noindent The rebuild is the reviewer's receipt. If it succeeds, the reviewer
learns that the theorem names in the PDF exist, the proof checker accepts them,
and the listed assumptions match the machine-readable trust report. If it fails,
the PDF claim is not ready to rely on.

\begin{lstlisting}[language=shell]
git clone git@github.com:lfglabs-dev/lido-srv3-proof-closure.git
cd lido-srv3-proof-closure
lake build SRv3Proofs
python3 scripts/check_trust_report.py reports/trust-boundary.json
\end{lstlisting}

\noindent In a production delivery, this command checks all selected theorem
files, verifies that every matrix row has a matching artifact, and rejects
unstated trust assumptions in the machine-readable report. In this report package, the
command is a contract for the handoff package rather than an executable artifact
shipped in this repository.
